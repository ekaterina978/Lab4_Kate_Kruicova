# Список для чтения (Практическая работа 4)

Приложение на чистом HTML, CSS и JavaScript: список записей с фильтрами,
сохранением в localStorage и черновиком в sessionStorage.

## Возможности

- Добавление записей (название обрезается по краям, пустой ввод отклоняется).
- Переключение статуса «К прочтению» / «Прочитано» и удаление записей.
- Фильтры «Все», «К прочтению», «Прочитано» с подсветкой активного и
  сообщением, если в режиме нет записей.
- Список и выбранный фильтр сохраняются в localStorage (JSON).
- Черновик ввода сохраняется в sessionStorage и восстанавливается после
  перезагрузки; после добавления записи ключ удаляется через `removeItem()`.
- Чтение/запись обёрнуты в try/catch; JSON проверяется (массив + поля записей).
  При повреждении данных показывается предупреждение и открывается пустой список.

## Ключи хранилищ

- `readingList.items` — массив записей в localStorage.
- `readingList.filter` — выбранный фильтр в localStorage.
- `readingList.draft` — черновик ввода в sessionStorage.

## Запуск через Live Server

1. Установите расширение **Live Server** в VS Code.
2. Откройте папку проекта в VS Code.
3. Правый клик по `index.html` → **Open with Live Server**
   (или кнопка **Go Live** в статус-баре).
4. Браузер откроет `http://127.0.0.1:5500/index.html`.

## Проверки в DevTools

- **Application → Local Storage**: ключи `readingList.items` и
  `readingList.filter`; после перезагрузки восстанавливаются.
- **Application → Session Storage**: ключ `readingList.draft`; после добавления
  записи исчезает.
- **Новая вкладка**: sessionStorage не разделяется между вкладками, поэтому
  черновик виден только в исходной вкладке; список (localStorage) виден везде.
- **Повреждённые данные**: заменить значение `readingList.items` на `broken` →
  после перезагрузки появится предупреждение, список пуст, добавление работает.
